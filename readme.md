# Portfolio Backend Developer - Dark Mode

## 🚀 Sobre o Projeto

Um portfólio moderno e interativo desenvolvido para desenvolvedores backend, com design elegante em dark mode e elementos neon. O site apresenta uma interface intuitiva com animações suaves e responsividade completa.

## ✨ Características

- **Design Dark Mode** com detalhes em neon
- **Animações Suaves** usando AOS (Animate On Scroll)
- **Layout Responsivo** e moderno
- **Seções Interativas**:
  - Hero com apresentação profissional
  - Sobre com experiência e especialidades
  - Skills com cards organizados por categorias
  - Projetos destacados
  - Contato integrado

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript
- [AOS](https://michalsnik.github.io/aos/) - Animate On Scroll Library
- [Font Awesome](https://fontawesome.com/) - Ícones

## 🎨 Features de Design

- **Tema Dark**: Esquema de cores escuro com detalhes em neon
- **Cards Interativos**: Efeitos hover e animações suaves
- **Typography**: Fonte moderna para melhor legibilidade
- **Ícones**: Integração com Font Awesome
- **Efeitos Visuais**: Sombras e transições suaves

## 📱 Responsividade

- Layout fluido adaptável
- Design mobile-first
- Breakpoints otimizados
- Menu responsivo

## 💻 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/vito-ysl/portfolio-backend.git
```

2. Navegue até o diretório:
```bash
cd portfolio-backend
```

3. Abra o arquivo `index.html` em seu navegador ou use um servidor local:
```bash
python -m http.server 8000
```
